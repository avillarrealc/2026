## 2. Nuestro motor G80-7T y el cálculo 5:1

El G80 es un motor compuesto de 29 mm clase G. El 7T es retardo de 7 segundos para eyección. La instalación del motor la hacemos nosotros, con retén y montura propios.

Fórmula oficial que piden los jueces:

```
Masa máxima (kg) = Empuje promedio del motor (N) / (5 x 9.81)
Masa máxima (g) = resultado x 1000
```

Ejemplo guía con valores típicos de un G80: empuje promedio unos 80 N.

```
80 / (5 x 9.81) = 80 / 49.05 = 1.63 kg = 1630 g
```

Ese número es el techo con ese ejemplo. El valor real se calcula con el empuje promedio del certificado del motor que compremos. Copien aquí los datos del empaque:

| Dato del motor comprado | Valor real |
| :--- | :--- |
| Empuje promedio (N) | ___ N |
| Empuje máximo (N) | ___ N |
| Impulso total (N-s) | ___ N-s |
| Masa máxima 5:1 calculada | ___ g |
| Meta interna de diseño, 150 g por debajo | ___ g |

Regla de oro: diseñen 150 g por debajo del techo para tener colchón de balanza y viento.
